GitHub Pages Static URL Parameter API (CubeTag64)

Yes! GitHub Pages serves static HTML/JS with full access to window.location.search and window.location.hash. This file already parses URL parameters on load so any inventory app (Homebox, Snipe-IT, Grocy, Home Assistant) can call it like an API!

Parameter Values / Format Example What It Does
code, title, sub Strings (Single Tag) ?code=TL-014&title=TORX+T8&sub=Precision Generates a single tag directly from URL variables (ideal for Homebox/Snipe-IT templates).
items Semicolon `;` separated ?items=IT-01|USB-C|2m;TL-14|TORX|T8 Populates an entire multi-tag chain strip in a single URL call.
sym datamatrix | qr | code128 &sym=datamatrix Selects the 1-bit integer barcode symbology.
scale auto | 2 | 3 | 4 | 5 &scale=4 Locks exact integer dots per module (`4` = 4×4 thermal dots per square).
layout side | compact | codeonly &layout=side Chooses 2-line text, single-line compact ID, or square code only.
action png | rawimg | py &action=png `png` auto-downloads the 64px PNG; `rawimg` replaces the page with a pure `<img>` tag; `py` auto-downloads `print_p300bt.py`.

What Your Test Print Photo Revealed (And How v1.1 Fixed It!)

Look closely at your photo: the 12×12 DataMatrix squares and dashed cut lines came out razor-sharp (and scanned right away because ECC 200 decoders handle mirrored matrices), but the text (TL-014 / TORX T8) printed vertically mirrored!

Why? In Brother's 16-byte (128-bit) raster column format, bit 32 corresponds to the top of the horizontal tape as it feeds left-to-right out of the slot. In v1.0, mapping bitPos = 32 + (63 - y) flipped the Y-axis upside down. In v1.1 (now active by default under Head Y-Order: Normal (Fixed)), we map bitPos = 32 + y so your text and DataMatrix print right-side up!

1. The Bluetooth-to-UART Bridge

On the MBH7BTZ42A-100101 board, the Bluetooth module identifies in packet captures with a Fujitsu OUI and speaks standard Bluetooth Classic SPP (RFCOMM channel 1)—not locked-down BLE!

The MCU behind it runs the exact same PTCBP raster command set documented for Brother's industrial PT-9500PC and PT-P710BT printers.

2. The 128-Bit / 64-Dot Geometry

Each vertical column sent over Bluetooth is 16 bytes (128 bits):

  • Bits 0–31 (4 bytes): Top unprinted padding (0x00)
  • Bits 32–95 (8 bytes): 64 active thermal dots!
  • Bits 96–127 (4 bytes): Bottom padding (0x00)
3. Cassette Sensor Hole Hack

Inside the tape bay is a cluster of mechanical microswitches that read the plastic holes on the bottom of the TZe cartridge.

By covering specific identification holes with electrical tape, the PT-P300BT prints on cheap AliExpress HSe heat-shrink tubing for labeling cables directly!
